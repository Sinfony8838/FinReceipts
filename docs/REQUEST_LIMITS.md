# 请求大小、上传时限与响应超时

客户端超时不代表后台工作已经停止。本轮为 API 增加输入字节限制、完整上传时限和响应等待
时限，同时保留已运行线程的执行名额、持久化任务的状态及调用预算。

## 问题与处理

基线 `115aa0e` 没有统一的 HTTP 请求体上限。新增负例把超过测试配置上限的有效 JSON
提交到真实问答路由，旧实现仍进入模型图。仅靠 Pydantic 字段验证不能限制 JSON 解析前的
内存占用；仅靠模型 SDK 的网络超时也不能限制整次 HTTP 等待。

[实现](../src/finreceipts/app/limits.py)采用以下顺序：

1. 验证主机与浏览器来源；开销较大的入口检查执行名额，满载立即返回 503，不读取正文。
2. `/api` 和 `/api/*` 检查编码后查询参数、声明长度和实际收到的正文字节，限时收齐后再解析 JSON。
3. 对受执行准入保护的路由启动响应计时。到期后关闭许可并隔离迟到输出，停止等待 ASGI 任务。
4. 实际同步线程退出后才释放名额。HTTP 超时不自动调用任务取消接口，也不重置预算。

上传期间会占用受保护路由的请求名额，但尚未开始模型或持久化节点。完整上传时限从服务端
开始接收正文计起，不会因每收到一个小块就重新计时。健康查询、静态资源不经过正文限制；
任务查询、取消、恢复仍有 API 输入限制，但不占执行名额、也不受执行响应时限限制。

## 配置和错误契约

| 配置 | 默认值 | 接受范围 |
| --- | ---: | --- |
| `FINRECEIPTS_MAX_REQUEST_BYTES` | 262144 字节（256 KiB） | 整数 1024 至 16777216 |
| `FINRECEIPTS_REQUEST_READ_TIMEOUT_S` | 10 秒 | 大于 0、不超过 60 的有限数 |
| `FINRECEIPTS_RESPONSE_TIMEOUT_S` | 120 秒 | 大于 0、不超过 600 的有限数 |

查询字符串固定限制为 **16384 字节**，按 URL 编码后的实际字节计算。响应等待从完整输入
接收之后计时。非法配置，包括 NaN 和无穷大，在启动时拒绝；Compose 转发这三个环境变量。

| 情况 | HTTP / 事件 | 错误码 |
| --- | --- | --- |
| 声明长度或实际正文超过上限 | 413 | `request_too_large` |
| 查询字符串过长 | 414 | `query_too_large` |
| 完整正文接收超时 | 408 | `request_body_timeout` |
| 重复、非法或不一致的 Content-Length；与 Transfer-Encoding 并存 | 400 | `invalid_request_framing` |
| 非 identity 的 Content-Encoding | 415 | `unsupported_content_encoding` |
| 响应等待到期，尚未发送响应头 | 504 | `response_timeout` |
| SSE 已开始后等待到期 | 已发送的 HTTP 200，最后一个 `event: error` | `response_timeout` |

错误携带服务端请求编号、安全说明及私有 API 的 `no-store` 响应头，不回显输入或异常内容。
输入拒绝后 HTTP/1 响应关闭连接，避免继续复用有未读正文的连接。分块传输由 ASGI 服务器
解码后逐块计数，不能通过省略或伪造 Content-Length 绕过。压缩请求体不在应用内解压。
代理或 ASGI 服务器也可能在应用之前拒绝非法 HTTP；这些检查不是 HTTP 协议解析器或请求走私防护证明。

## 数值分析的计算边界

HTTP 字节限制不能单独约束正则或逐条审计的 CPU 开销。数值提取器另有固定边界：
每次最多 **65,536 个 Unicode 字符、256 个提取到的数值**。被忽略的年份、日期和标识符
不占数值名额；精确到达边界允许，超过边界整次拒绝，不返回可能被误认为完整审计的前 256 项。
该限制也适用于 CLI 和模型答案的数值核验，不随 HTTP 正文上限调大而变化。

`POST /api/audit` 对超限返回 **422 / `audit_input_limit`**；数字转成浮点数或乘以单位倍率后
不再有限时，返回 **422 / `numeric_out_of_range`**，不把无穷值放进 JSON。错误带请求编号，
不回显原文。CLI 返回退出码 2 和简短说明，不写出部分报告。调用者应按完整句子分段，
在每段保留明确公司、财年和指标；拆段不能用来改变原句的范围或把部分通过拼成全文正确。

输入和证据本身有限、但相对误差因零分母或运算溢出而不可用时，`relative_error` 为 `null`。
核验结论和证据仍正常返回，不把不可用误差写成 0，也不因错误金额与零值证据比较而返回 500。

模型生成的超限内容经过同一提取器。持久化工作流沿既有失败路径进入 `interrupted`，
已发生的模型调度预算保留，不能获得数值通过标记。它不是客户端文本参数错误；不会自动
重试或退还预算。恢复同一未改动的异常答案仍可能遇到同一错误，应先检查输出和任务范围。

数值提取从非空白字符开始，并使用 Python 3.11+ 的占有式空白匹配，避免无数字时反复
分配同一段空白。句子切分只检查缩写所需的末尾六个字符，不在每个数字处重扫所有前文。
允许的 256 句审计在本机实验中由超过 8 秒未完成降至约 0.135 秒；64 Ki 字符的空白输入约
0.008 秒。它们是 Windows 单次受控测量，不是任意文本的时延上界或生产容量承诺。

测试与原始超时记录位于 `runs/numeric-input-20261018/`。新增回归覆盖边界、拒绝后名额
释放、正常请求恢复、CLI、不良模型输出的预算与导出完整性；另有两组各 1,000 个确定种子
的差分样本，分别检查数字内容/跨度及句子切分一致性。安装包门禁也检查真实 HTTP 的拒绝响应。

## 超时后的操作

持久化任务超时后先查询原 run ID。如果节点已提交，继续当前 `revision` 的下一步；如果仍在
运行，可以等待或明确取消。显式取消撤销 worker token，晚到结果不能提交。仅 HTTP 超时后，
原节点仍可以提交为 `ready / verify`，调用预算仍计一次。不要把 504 当成“服务端没执行过”。

快速问答不保存为可恢复任务，超时后迟到回答被丢弃；等待名额释放后手动重试可能产生新的调用。
浏览器不会因超时自动发起第二次请求。SSE 消费方必须处理错误事件，不能只看 HTTP 200。

同步 SDK 线程无法安全强制终止。响应时限只限制客户端等待，不是模型账单或线程执行的硬截止：
已进入的同步图执行仍可能继续内部步骤，模型 SDK 自身的网络超时和重试策略仍独立生效。
实现用 `asyncio.wait` 观察任务完成，超时后请求取消并保留任务引用、获取迟到异常，防止异常
文本落入未处理任务日志。Python 文档也明确：[取消任务不是强制终止，等待取消可能超过时限](https://docs.python.org/3.11/library/asyncio-task.html)。

这些限制是单进程应用边界，不是反向代理级连接数、总内存、请求头或路径长度限制。慢客户端
发送和网络背压仍受服务器与部署环境影响；这里不承诺精确的端到端墙钟 SLA 或公网抗压能力。

## 验证与复现

[回归测试](../tests/test_request_limits.py)覆盖 UTF-8 字节边界、缺失及伪造长度、分块跨限、
不完整上传、断连、挂载前缀、满载不读正文、配置边界，以及普通/SSE/durable 请求的实际阻塞
模型。持久化负例分别验证超时后正常提交、显式取消后拒绝迟到提交，两者均保留一次调用预算。
另用忽略取消的任务验证超时后的响应不能追加，且迟到异常被获取。

[本地演练](../scripts/request_limits_smoke.py)启动隔离回环服务，使用新数据库、FakeLLM 和离线
事实。真实 TCP 慢上传返回 408，超限 JSON 与分块正文返回 413，模型调用数均为 0；普通请求
返回 504，SSE 以错误事件结束，此时后台模型仍阻塞，`active=1`，新执行被 503 拒绝。
释放模型后名额归零。可选 Edge 测试验收桌面及手机宽度的超时文案、请求编号和未完成状态。

```powershell
python -m pytest tests/test_request_limits.py tests/test_admission.py -q
python scripts/request_limits_smoke.py --out runs/review-limits-001
# 有 Playwright 和 Edge 时，用 --node 传入 Node 路径，并在 NODE_PATH 配置依赖目录。
```

输出目录必须不存在；脚本只停止本次启动的 Fake 服务，不覆盖原有记录或运行库。
本机原始输出位于 `runs/request-limits-20261018/`，失败夹具与浏览器同步调整的记录一并保留。
验证范围是 Windows 本机、真实回环 HTTP 和 Edge；没有真实模型调用、远程 CI 或生产流量。

符号链接权限。最终 HTTP 与 Edge 演练为 PASS，4 次受控模型调用的并发峰值为 1，结束时
执行名额归零。Python 实现摘要为
`62088e66889a1b9a087d52f53e3c3623b960dbb0eacef798af71fa6ea0be5998`；页面与脚本另由本地
`evidence.json` 记录文件摘要。该结果不覆盖 Docker 重建，后者仍为 BLOCKED_UNRUN。
