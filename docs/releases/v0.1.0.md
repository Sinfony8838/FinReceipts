# FinReceipts 0.1.0 · Evidence Workbench

本次预览版将财务数值核验扩展为可保存、可恢复、可复查的研究工作台。

## 主要更新

- 固定任务使用的财务证据，保存 JSON 检查点与执行事件。
- 调用前预留模型和工具额度，通过状态版本及租约拒绝并发旧结果。
- 支持显式恢复、取消、事件游标补读、证据导出及完整性校验。
- 在同一份回答和证据上对照数字匹配与受支持年度语句核验，无额外模型调用。
- 增加 SEC 观测快照、采集记录和事实绑定目录。
- 统一中文工作台与问答页面，提供浅色、深色、跟随系统主题及移动端布局。

## 本地验证

- 完整离线回归：633 passed / 1 skipped。跳过项为 Windows 符号链接权限，Linux CI 另行执行。
- Ruff 检查与格式检查通过，uv 锁文件检查通过。
- 64 组浏览器布局检查通过，包括五种宽度、三种主题、原生 200% 缩放及明确的异常状态夹具。
- 真实离线接口的创建、推进、修订、刷新、事件补读、导出、复核、取消和问答流程通过。
- 独立 wheel 环境验证页面资源及创建、推进、导出接口；源码包和 wheel 包含版本 0.1.0。

本地原始记录：`runs/release-0.1.0-20261014/`。
GitHub CI 的结果以 PR 和合并提交对应的工作流为准。

## 使用

从源码检出后，按 [中文启动说明](../../README.zh-CN.md#本地启动)运行，
打开 `http://127.0.0.1:8000/workbench`。默认演示使用 fake 模型与离线 SEC fixtures，无需模型密钥。

Release 提供源码包、wheel 和 SHA-256 清单。wheel 不内置 SEC 演示缓存；
完整离线演示应使用源码包或 Git 检出目录。

## 范围

这是本地研究预览版。恢复以已提交节点为边界，未知结果的外部调用可能重复；
调度额度不等于账单上限，数字匹配不代表全文正确，快照摘要不证明历史公开时间。
离线演示与合成测试不作为真实模型质量或生产安全结论。
