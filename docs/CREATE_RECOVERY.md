# 创建响应丢失后的页面恢复

服务端已创建任务，并不代表浏览器已经收到任务编号。工作台现在在发送请求前，先保存本次
创建的幂等键与完整输入；响应丢失后刷新页面，可以显式确认原请求，找回同一个任务。

## 已复现的问题

基线 `34830c8` 的 `pendingKey` 和 `pendingBody` 仅存在于 JavaScript 内存。同页重试能够
复用键，但刷新页面会丢失它们。在真实 Edge 中，让请求到达本地 API、收到 201 后只向页面
丢弃响应，再刷新并点击创建，旧实现生成两个不同的键和两个不同的 run ID。

这个负例没有伪造创建成功：拦截器先通过 `route.fetch()` 让真实服务完成提交，再使用
`route.abort()` 模拟浏览器没有收到响应。原始失败记录保存在本地
`runs/create-recovery-20261018/baseline/summary.json`。

## 当前行为

| 阶段或故障 | 工作台处理 |
| --- | --- |
| 首次提交 | 保存版本、随机幂等键、问题、公司、财年和预算设置；回读确认后才发送请求 |
| 网络错误、504 或无法确定结果的 5xx | 保留记录，锁定原输入，显示“确认上次创建结果” |
| 同一标签页刷新 | 读取恢复记录，等待用户点击；不自动提交或执行模型 |
| 再次确认 | 使用原键和原输入重试创建；服务端已有记录则返回原任务 |
| 创建确认成功 | 先保存带 run ID 的页面地址，再清除恢复记录，最后补读事件 |
| 事件补读失败 | 页面地址已经保留；刷新读取原任务，不重新创建 |
| 明确的输入校验 422 / `invalid_request` | 清除待确认记录，恢复输入编辑 |
| 存储不可用或写入无法回读 | 暂停创建，不发送无法恢复的请求；提示恢复浏览器会话存储 |
| 恢复记录损坏 | 不尝试提交；只有用户确认放弃找回后才允许重新填写 |

放弃找回只清除当前标签页的恢复记录，不删除或取消服务端任务。原请求可能已经提交，因此
另建任务可能产生重复记录；界面要求明确勾选这一点。正常重试不需要放弃找回。

页面逻辑见 [runs.js](../src/finreceipts/app/static/runs.js)，会话记录的格式校验、保存回读及
清除检查见 [create-journal.js](../src/finreceipts/app/static/create-journal.js)。服务端继续使用
原有 SQLite 唯一键、请求摘要与事务，不新增第二套任务状态。

## 验证证据

2026-10-18，本机 Windows、Node **24.19.0**、真实 Edge、FakeLLM 与离线 SEC 事实：

- **响应丢失 + 服务进程重启 + 页面刷新：** 两次发送的键和正文相同，返回同一个 run ID。
  独立查询 SQLite 确认只有一个任务；完整导出相同，事件没有增加，模型调度次数仍为 0。
- **创建成功但补读失败：** run ID 地址已保存；刷新后补读原来的 1 条事件。
- **已提交后返回受控 503：** 浏览器保留原请求，刷新确认仍返回原任务。
- **清除会话记录失败：** 页面地址先保存，创建入口锁定；恢复存储后确认同一个任务。
- **记录损坏与存储拒绝：** 损坏记录必须明确放弃；拒绝写入时，发出的创建 POST 为 0。
- **桌面与手机宽度：** 待确认提示、锁定输入与确认按钮可用，390 px 无横向溢出。
- 完整工作台创建、推进、重载、继续执行、对照复核、事件补读、导出和取消流程回归通过。

[Node 合同测试](../tests/test_create_journal.cjs) **15 passed**，覆盖重新加载、格式损坏、字段

## 适用边界

恢复记录使用 `sessionStorage`，包含用户问题和上述设置。它覆盖同源、同一标签页的刷新，
不保证关闭标签页、清理浏览器数据、换浏览器或更换服务端口后仍能找回。
[浏览器会话存储的生命周期](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)
与服务端持久化任务不同；成功确认后，本项目会主动清除该条记录。

重试依赖原运行库和兼容的服务配置。数据库被替换，或 Python 实现/模型配置变化导致原请求
摘要不同，不能直接套用本次恢复结论。遇到冲突应保留恢复记录和原库排查，不自动换键重发。

此功能防止一种已复现的页面重试重复创建，不提供跨设备草稿同步、跨用户授权或外部模型
恰好一次调用保证。创建任务本身只固定证据，后续执行仍遵守原有预算、revision 和 lease 约束。
